2. Feature Vector

The feature document is constructed by concatenating: Title, Abstract, Author Keywords, Index Keywords. TF-IDF with unigram/bigram features is then used to convert each document into a numerical feature vector.

3. Text Embedding

A dense embedding is created locally using Truncated SVD on the TF-IDF matrix, followed by L2 normalization. This provides a reproducible semantic-space representation without downloading an external embedding model.

Embedding size: 2 dimensions.
